You write the Python generator for a given competition-math problem family.

A family is a problem statement with parameters. Its generator draws those parameters from `rng = random.Random(seed)`, computes the answer, and returns the statement with the parameters filled in. You are shown several worked transformations from a reference family and its generator to a new family and its generator, and then a reference pair and a new family of your own to finish.

In every one of them the reference generator is a model of the CODE and never of the mathematics: the new family asks a different question, so its parameters, its answer route and its check route are all its own. Reuse something from the reference only where it stays mathematically correct for the new family.

Reply with exactly one fenced ```python block and nothing else.

The generator must:
- define `generate(seed)` and return `problem, str(answer)`;
- draw every parameter from `rng = random.Random(seed)`;
- emit exactly the family you were given, with its parameters substituted -- same question, same wording;
- give every sampled parameter a visible effect on the statement and on the answer;
- compute `answer` by solving the family's question;
- compute `check` by a materially different route -- brute force over the stated domain unless it is too large to walk -- that neither reuses `answer` nor restates its formula;
- contain `assert answer == check, f"answer={answer} check={check}"`;
- define or import everything it references;
- run for seeds 0-4 in seconds and produce at least two distinct problem texts.

Do not write GROUP or SKILL lines; they are added afterwards.

HOW ANSWER AND CHECK PAIR UP, BY SKILL. These are toy sketches of the two-route
discipline, not problems to reuse: the answer route uses the skill, the check
route never does.

casework -- answer adds up the cases, check walks the whole domain unsplit:
    answer = 2 * (m - t) if t < m else 0
    check = sum(abs(x) > t for x in range(-m, m + 1))

induction -- answer is the closed form, check runs the recurrence literally:
    answer = 1 + (n - 1) * d
    f = 1
    for _ in range(n - 1):
        f = f + d
    check = f

contradiction -- answer is the proven bound, check searches for anything longer:
    answer = n            # a strictly decreasing chain from n has at most n terms
    def longest(v):
        return 1 + max((longest(w) for w in range(1, v)), default=0)
    check = longest(n)

invariant -- answer is the preserved quantity, check simulates the process in rng order:
    answer = n * (n + 1) // 2
    pool = list(range(1, n + 1))
    while len(pool) > 1:
        a = pool.pop(rng.randrange(len(pool)))
        b = pool.pop(rng.randrange(len(pool)))
        pool.append(a + b)
    check = pool[0]

extremal_principle -- answer is the sharp bound, check exhausts every configuration:
    answer = sum(range(n, 0, -2))
    check = max(sum(k + 1 for k in range(n) if mask >> k & 1)
                for mask in range(1 << n) if not mask & (mask << 1))

counting -- answer is the counting formula, check enumerates one by one:
    answer = n * (n - 1) // 2
    check = sum(1 for x in range(1, n + 1) for y in range(x + 1, n + 1))

transformation -- answer counts in the transformed representation, check scans directly:
    answer = sum(2 - (d * d == n) for d in range(1, int(n ** 0.5) + 1) if n % d == 0)
    check = sum(1 for x in range(1, n + 1) if n % x == 0)

construction -- answer constructs the object, check finds it by blind search:
    answer = (b // a + 1) * a
    x = b + 1
    while x % a:
        x += 1
    check = x

Four worked transformations follow, in exactly the shape of the task. Read them for two things: the reference generator is a model of the CODE, never of the mathematics, and `check` always walks the stated domain by a route that shares no algebra with `answer`. That cross-check is the only thing proving the statement and the number describe the same mathematics, so a `check` that recomputes `answer` a second way is worth nothing.


WORKED EXAMPLE 1

EXAMPLE -- this family

Let N = {N}. How many positive divisors does N have?

is produced by this generator:
```python
import random

def generate(seed):
    rng = random.Random(seed)
    N = rng.randint(20, 100)

    root = int(N**0.5)
    answer = sum(N % d == 0 for d in range(1, root + 1)) * 2
    if root * root == N:
        answer -= 1

    check = sum(N % d == 0 for d in range(1, N + 1))
    assert answer == check, f"answer={answer} check={check}"

    problem = f"Let N = {N}. How many positive divisors does N have?"
    return problem, str(answer)
```

NOW WRITE THE GENERATOR FOR THIS FAMILY

Count the primes p with {lower_limit} <= p <= {upper_limit}.

CORRECT OUTPUT:
```python
import random

def generate(seed):
    rng = random.Random(seed)
    lower_limit = rng.randint(10, 60)
    upper_limit = lower_limit + rng.randint(20, 60)

    def is_prime(k):
        if k < 2:
            return False
        d = 2
        while d * d <= k:
            if k % d == 0:
                return False
            d += 1
        return True

    answer = sum(is_prime(k) for k in range(lower_limit, upper_limit + 1))

    sieve = [True] * (upper_limit + 1)
    sieve[0] = sieve[1] = False
    for d in range(2, int(upper_limit ** 0.5) + 1):
        if sieve[d]:
            for m in range(d * d, upper_limit + 1, d):
                sieve[m] = False
    check = sum(sieve[k] for k in range(lower_limit, upper_limit + 1))
    assert answer == check, f"answer={answer} check={check}"

    problem = f"Count the primes p with {lower_limit} <= p <= {upper_limit}."
    return problem, str(answer)
```

NOW WRITE THE GENERATOR FOR THIS FAMILY

From the integers 1 through {element_count}, a subset is chosen in which no two chosen integers are consecutive. Find the maximum possible sum of such a subset.

CORRECT OUTPUT:
```python
import random

def generate(seed):
    rng = random.Random(seed)
    element_count = rng.randint(8, 14)

    answer = sum(range(element_count, 0, -2))

    check = 0
    for mask in range(1 << element_count):
        if mask & (mask << 1):
            continue
        total = sum(k + 1 for k in range(element_count) if mask >> k & 1)
        check = max(check, total)
    assert answer == check, f"answer={answer} check={check}"

    problem = f"From the integers 1 through {element_count}, a subset is chosen in which no two chosen integers are consecutive. Find the maximum possible sum of such a subset."
    return problem, str(answer)
```

NOW WRITE THE GENERATOR FOR THIS FAMILY

A walk starts at (0, 0) and ends at ({width}, {height}), moving one unit right or one unit up at each step. How many such walks are there?

CORRECT OUTPUT:
```python
import random
from math import comb

def generate(seed):
    rng = random.Random(seed)
    width = rng.randint(3, 8)
    height = rng.randint(3, 8)

    answer = comb(width + height, width)

    def walks(x, y):
        if x == width and y == height:
            return 1
        total = 0
        if x < width:
            total += walks(x + 1, y)
        if y < height:
            total += walks(x, y + 1)
        return total
    check = walks(0, 0)
    assert answer == check, f"answer={answer} check={check}"

    problem = f"A walk starts at (0, 0) and ends at ({width}, {height}), moving one unit right or one unit up at each step. How many such walks are there?"
    return problem, str(answer)
```

NOW WRITE THE GENERATOR FOR THIS FAMILY

Let A = (0, 0), B = ({a}, 0), and C = (0, {b}). How many lattice points lie strictly inside triangle ABC?

CORRECT OUTPUT:
```python
import random
from math import gcd

def generate(seed):
    rng = random.Random(seed)
    a = rng.randint(3, 10)
    b = rng.randint(3, 10)

    answer = (a * b - a - b - gcd(a, b) + 2) // 2

    check = sum(
        b * x + a * y < a * b
        for x in range(1, a)
        for y in range(1, b)
    )
    assert answer == check, f"answer={answer} check={check}"

    problem = f"Let A = (0, 0), B = ({a}, 0), and C = (0, {b}). How many lattice points lie strictly inside triangle ABC?"
    return problem, str(answer)
```
