- casework: The solution must split into explicitly named cases (by residue, sign, or size order), each case needs its own argument, and no single uniform formula covers all of them.
- induction: The problem is built on a recursive structure of size n with n >= 30, so the answer is reached only by relating size n to smaller sizes, never by unrolling step by step.
- contradiction: The answer depends on proving that a described object cannot exist, and the candidates to rule out are unbounded, so no finite check can settle it.
- invariant: The problem states a repeatable move with no step limit, and only a conserved quantity (parity, residue class, monotone value) decides which states are reachable.

- counting: The answer is the size of a finite set too large to list, so it must be computed structurally with complement counting, inclusion-exclusion, the product rule, or a bijection.
